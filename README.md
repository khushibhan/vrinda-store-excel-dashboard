# Vrinda Store Annual Report

An Excel dashboard I created to analyze Vrinda Store's sales and order data.

## About the Project

I worked on this project to understand how sales data can be converted into useful business insights using Excel.

The dashboard covers:
- Monthly sales and order trends
- Sales comparison between men and women
- Category-wise sales
- Order status
- Top 5 states by sales
- Age and gender-wise orders

## Excel Features Used

- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Creation

## Dashboard

The dashboard is interactive and includes slicers for:
- Month
- Channel
- Size

These filters can be used to view the data based on different selections.

## Key Insights

- Women contribute a larger share of the total sales compared to men.
- Maharashtra, Karnataka and Uttar Pradesh are among the top states by sales.
- The dashboard shows which product categories contribute the most to overall sales.
- Most orders are successfully delivered, while cancelled, returned and refunded orders make up a much smaller portion.
